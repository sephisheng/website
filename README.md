# Sephi Sheng Website

Upload the contents of this folder to the GitHub repository `sephisheng/website`.

## File structure

- `index.html` — homepage
- `assets/css/style.css` — all styling
- `assets/js/app.js` — small interaction script
- `assets/images/hero.jpg` — hero photo
- `assets/images/byu-y.png` — BYU logo
- `style/index.html` — Shop My Style page
- `playlist/index.html` — Match Day Playlist page
- `gear/index.html` — What’s In My Bag page
